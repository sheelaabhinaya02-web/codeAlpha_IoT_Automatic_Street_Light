# Automatic Street Light using LDR

## Project Description
This project automatically controls a street light
using an LDR sensor and Arduino Uno.

## Components
- Arduino Uno
- LDR sensor
- 10kΩ resistor
- 220Ω resistor
- LED
- Breadboard
- Jumper wires

## Working
The LED turns ON in low-light conditions
and turns OFF in bright-light conditions.

## Simulation
Created and tested using Tinkercad.
